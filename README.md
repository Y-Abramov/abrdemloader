# ABR | CIVIL - Загрузка рельефа

Строит поверхность Civil 3D по рельефу из открытых источников: указывается область в
чертеже, модуль качает нужные тайлы, пересчитывает высоты в систему координат чертежа и
строит поверхность (`TinSurface`). Нужен, чтобы под трассой или площадкой на предпроектной
стадии сразу лежал реальный рельеф, а не пустой лист - без ручного поиска и склейки листов
DEM.

## Поддерживаемые версии Civil 3D

| Civil 3D | Серия |
|---|---|
| 2015-2024 | R20.0-R24.3 |
| 2025 и новее | R25.0+ |

## Команды

| Команда | Действие |
|---------|----------|
| `DEMLOAD` | Построить поверхность: область в чертеже, источник, шаг сетки, поправка Z |
| `DEMUPDATE` | Перестроить поверхность по сохранённому заданию (например, после переноса трассы) |
| `DEMERASE` | Убрать поверхность и задание модуля из чертежа |
| `DEMEXPORT` | Выгрузить файлы источника на область в папку, без построения поверхности |
| `DEMSETTINGS` | Настройки: ключ OpenTopography, лимит точек, таймаут, папка кэша |
| `DEMABOUT` | О модуле |

## Источники

Встроены два источника без ключа - **Copernicus GLO-30** (шаг ~30 м) и **Copernicus
GLO-90** (шаг ~90 м), оба раздаются через открытый бакет `copernicus-dem-*-m.s3.amazonaws.com`
без регистрации.

**OpenTopography - по личному ключу пользователя, в поставку не входит.** Условия сервиса
прямо запрещают вшивать ключ в приложение и раздавать его третьим лицам (см. doc-comment
`Core/Sources/OpenTopoRequest.cs`) - точно та же причина, по которой AbrBasemap не везёт с
собой платные тайловые сервисы. Модуль поставляет только сам протокол запроса; ключ вводится
в `DEMSETTINGS` и используется только с локальной машины пользователя.

### Как получить ключ OpenTopography

1. Зарегистрироваться (бесплатно): https://portal.opentopography.org/requestService?service=api
2. Скопировать API-ключ из личного кабинета.
3. Вставить в `DEMSETTINGS` → поле «Ключ OpenTopography».

## Данные Copernicus: что это и для чего годится

Copernicus DEM (GLO-30, GLO-90) - © DLR e.V. и Airbus Defence and Space GmbH, предоставлено
программой COPERNICUS Европейского союза и ЕКА. Дополнительно - OpenTopography, по личному
ключу пользователя.

Данные Copernicus - цифровая модель поверхности (DSM): включает кроны деревьев и крыши.
Высоты отсчитываются от геоида EGM2008. Это подложка для посадки объекта и предварительных
объёмов, не основа проектных отметок.

- **Годится:** прикидка посадки объекта на местности, предварительные объёмы земляных масс,
  общее представление о рельефе площадки на ранней стадии.
- **Не годится:** замена инженерных изысканий, основа для проектных отметок и точных
  объёмов - точность и характер поверхности (DSM, не голая земля) для этого недостаточны.

## Что появляется в чертеже

- Поверхность Civil 3D (`TinSurface`) с именем, заданным в диалоге.
- Задание (область, источник, шаг, поправка Z, имя поверхности) хранится в словаре чертежа -
  на нём работают `DEMUPDATE` и `DEMERASE`.

## Иконки

Иконки ленты в этой версии - **временные плацехолдеры**, сгенерированы скриптом
`icons/generate-placeholders.ps1` (простые плоские глифы: рельеф со стрелкой загрузки,
круговая стрелка обновления, крест удаления, шестерня настроек, "i" в круге - о модуле).
Технику и палитру скрипт наследует у `civil3d/distmaps/icons/make-icons.ps1` (AbrBasemap) -
тот же визуальный вес по линейке. Финального дизайна нет, юзер перерисует по желанию позже;
скрипт можно перезапустить и подправить глифы без участия Claude.

## Известные ограничения

- Данные - DSM, не голая земля: кроны деревьев и крыши учтены в высоте.
- Клетка Copernicus качается целиком (десятки мегабайт на клетку 1x1 градус) - у `DEMEXPORT`
  и `DEMLOAD` нет частичной подгрузки клетки по кускам, кроме тайлового чтения внутри самого
  файла.
- OpenTopography отдаёт данные по суточной квоте личного ключа - лимит и таймаут задаются в
  `DEMSETTINGS`.
- Без системы координат в чертеже строить нечего - назначьте её родной командой
  `MAPCSASSIGN` до `DEMLOAD`/`DEMEXPORT`.
